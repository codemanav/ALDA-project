# ALDA Soccer Analytics

This repository contains the Fall 2024 ALDA project for analyzing European
soccer data with exploratory data analysis and machine-learning models.

## Project focus

- Explore players, teams, leagues, and match data.
- Predict match outcomes from historical team and match attributes.
- Identify potential player transfers based on team needs and player
  performance.

## Repository structure

- `1_project_proposal/` - Project proposal and supporting source files.
- `2_midway/` - Midway analysis, prediction notebooks, and report materials.
- `3_project_presentation/` - Final presentation and transfer-candidate data.
- `4_final_report/` - Final report and LaTeX source.
- `5_final_codebase/` - Final Jupyter notebooks and prepared datasets.

## Final notebooks

The final analysis is in `5_final_codebase/`:

- `Matches_eda.ipynb`
- `Teams_eda.ipynb`
- `players_eda.ipynb`
- `match_outcome_prediction.ipynb`
- `Transfer_prediction.ipynb`
- `alda-project.ipynb`

The notebooks use the European Soccer Database tables for countries,
leagues, matches, players, player attributes, teams, and team attributes.
